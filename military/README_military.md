# 국방부 데이터 시점 예측 검증 (SABER-K)

지자체 데이터 검증(연 단위 계층 학습)과 별개로, **실제 국방부 세부사업 월별 집행
데이터**로 "분기 시점(as-of)에 연말 불용을 예측"하는 능력을 검증한다.

## 데이터
- 출처: 열린재정(openfiscaldata.go.kr) '재정사업 집행실적(월별집행실적)',
  소관=국방부, 2020~2025년 (공개 데이터). 세부사업 단위, 회계→프로그램→단위사업→세부사업 계층.
- `data_mil/` 폴더에 원본 xlsx를 넣거나, 전처리 캐시(`mil_panel.pkl`)를 사용.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `military_data.py` | 국방부 월별 xlsx 파서(원시 XML 직접 파싱) + as-of 패널 생성 |
| `saber_temporal.py` | 세이버-K 시점 예측 모델 (계층 앵커·gap 피처 + 부스팅) + 예측구간 |
| `compare_models.py` | 5개 방법 비교 + 계층 피처 ablation |
| `evaluate_military.py` | 전체 백테스트 실행 (시점별·비교·규모별 구간·조기식별) |

## 실행
```bash
pip install pandas numpy xgboost scikit-learn
python evaluate_military.py
```
`data_mil/mil_panel.pkl`(전처리 캐시)이 있으면 그것으로 즉시 실행되며, 없으면
`data_mil/*.xlsx` 원본을 파싱해 캐시를 생성한다.

## 백테스트 설계
- 학습 2020~2023 → 검증 2024(예측구간 보정) → 시험 2025년 231개 사업
- 예측 시점(예: 9월) 이후 정보는 완전 차단 (as-of 예측)
- 지표: RMSE (연말 집행률 예측오차)

## 핵심 결과 (9월 시점)
- **세이버-K(계층+트리) RMSE 0.085 — 5개 방법 중 1위**
  (트리 단독 0.098, 계층 베이지안 단독 0.100, 딥러닝 MLP 0.116, 선형 0.132)
- **계층 피처 ablation**: 같은 부스팅도 계층 피처 없이는 0.098, 계층 피처 통합 시 0.085
  → 성능의 핵심은 알고리즘이 아니라 계층 구조 설계 (변수 중요도의 약 64%가 계층 앵커)
- **분기가 진행될수록 정교**: 3월 0.152 → 6월 0.119 → 9월 0.085
- **예측구간**: 재배정 대상인 1,000억+ 사업에서 80% 구간 포함률 85.5%, 금액 가중 90.6%
  (전체 231건 기준 76.2%; 소액 사업은 변동성이 커 벗어남)
- **조기 식별**: 9월 시점 위험 상위로 걸러낸 사업 중 실제 연말 불용 적중률 63.2%

## 주의
- 본 검증은 세부사업 단위 공개 데이터이며, 부대 단위·내부망 데이터는 사용하지 않았다.
- 수치는 seed 고정 재현값이나, 라이브러리 버전에 따라 소수 셋째 자리에서 미세하게 다를 수 있다.
